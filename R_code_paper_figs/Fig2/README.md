To re-create all the plots, please use the scripts in the indicated Step order. The differences in the example scripts for Step1a and Step1b are small, and relates to minor changes when using a set of top genes instead of using the whole gene list. Files in this folder not named 'Step' contain data needed to re-create the plots and input for the scripts. All spatial data has been published elsewhere and links to the publications for the respective datasets can be found in 'Table_of_spatial_datasets.csv'
